# Análisis de Utilidad y Márgenes - Appol

Dashboard interactivo desarrollado en Power BI para analizar la utilidad y los márgenes de venta por país, continente y categoría de producto en el periodo 2017-2019.

## Contexto
Proyecto realizado siguiendo el curso "Microsoft Power BI - Curso de Power BI Desktop" 
de Javier Gómez (Udemy), como práctica de transformación de datos, modelado y 
visualización en Power BI Desktop.

## Contenido del dashboard
- KPIs de Utilidad total y Margen (%)
- Distribución de utilidad por continente
- Evolución de utilidad y margen por año y continente
- Mapa geográfico de utilidad por país
- Tabla comparativa de margen por país
- Segmentación por año, tipo de producto y categoría

## Herramientas
- Power BI Desktop
- Power Query
- DAX
